# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ChapterFlow, please report it responsibly.

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, email us directly at:

**chapterflow.app@gmail.com**

Include as much information as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge your report within 48 hours and aim to provide a resolution timeline as quickly as possible.

Thank you for helping keep ChapterFlow and its users safe.
