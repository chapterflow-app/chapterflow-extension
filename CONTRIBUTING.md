# Contributing to ChapterFlow

Thank you for your interest in contributing to ChapterFlow for YouTube™!

## How to Contribute

### 1. Reporting Bugs
- Check if the issue already exists
- Use the **Bug Report** template
- Include:
  - Chrome version
  - Extension version
  - Steps to reproduce
  - Expected vs actual behavior
  - Screenshots if possible

### 2. Suggesting Features
- Use the **Feature Request** template
- Clearly describe the problem and your proposed solution
- Explain why this would be useful for podcast / long-form listeners

### 3. Pull Requests
1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test thoroughly on YouTube videos with chapters
5. Commit with a clear message
6. Open a Pull Request against the `main` branch

### Development Setup
1. Clone the repository
2. Open Chrome → `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the extension folder
5. Make changes and click the refresh icon on the extension card

### Code Style
- Keep the extension lightweight and privacy-focused
- Prefer vanilla JavaScript / modern ES modules
- Avoid external dependencies when possible
- Comment non-obvious logic
